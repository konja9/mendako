# しんかいぷかぷか ゲームデザインメモ（v0.1）

> タイトルは仮。最初のキャラクターは めんだこ。

## コンセプト

- 深海いきものを **育てて・着せ替えて・眺めて癒やされる** ブラウザゲーム。
- 罰はゆるく。放置しても死なない・逃げない。「おなかすいた」「さみしい」と言う程度にとどめる。
- 深海の本物の知識を少しずつ混ぜる（めんだこの好物は小さな甲殻類、生息水深 200〜1000m、深海に届くプラスチックごみ など）。

## 2D か 3D か

| 観点 | 2D（SVG / Canvas） | 3D（three.js など） |
| --- | --- | --- |
| 着せ替えアイテムの制作 | パーツ画像を1枚描けば済む | モデリング＋体型ごとのフィッティングが要る |
| 生き物を増やすとき | 体の形に合わせて位置を調整するだけ | 生き物 × 全アイテムの調整が発生する |
| かわいさの出しやすさ | イラストのかわいさをそのまま出せる | ローポリ＋トゥーン調なら可能。絵作りの難度は高い |
| 深海の空間表現 | パララックスや光の演出で「それっぽく」 | 360°眺める、泳ぎ回る、光の減衰など強い |
| 動作の軽さ | スマホでも軽い | 端末の性能差が出る。読み込みも重い |
| 開発スピード | 速い | 遅い。遊びの検証前に時間を使いやすい |

**おすすめ：まず 2D で遊びの核を固める。**
着せ替えはアイテム数が遊びの量に直結するので、1アイテムあたりのコストが小さい 2D が有利。
ゲームの状態とロジック（`src/game/`）は描画から切り離してあるので、
後から「3D 観賞モード」や three.js 版の描画（`src/view/` の差し替え）を追加できる。

3D を本格的に選ぶ目安：着せ替えよりも「深海を泳ぎ回ること・探検すること」自体が主役になる場合。

中間案として **2.5D**（2D イラストを部位ごとに変形させる Live2D 風、奥行きのある背景レイヤー）もある。

## ゲーム性の候補（未決定）

### A. 育成を深くする
- 性格（くいしんぼう、あまえんぼう など）で好物や喜ぶ行動が変わる
- 育て方で成長後の見た目が分岐する（ヒレが大きい子、まるい子）
- 水槽のそうじ（せいけつ度）を追加する

### B. 着せ替えを広げる
- スロット追加（せなか、うでのさき）、セットでそろえるとボーナス
- 季節限定・イベント限定アイテム、色違い
- **写真モード**：背景とポーズを選んで撮影し、画像として保存する
- **水槽の模様替え**：岩・サンゴ・ライトなどを置く（着せ替えと並ぶもう一つの「飾る」遊び）

### C. 集める・探検する
- **深海図鑑**：仲間の生き物を増やしていく
- **深海探索**：水深を選んで潜り、そこでしか会えない生き物や素材を見つける
- 素材を集めて服を作る（クラフト）

### D. ミニゲームを増やす
- チョウチンアンコウの光に合わせるリズムゲーム
- 泡わり、かくれんぼ

### E. 毎日遊ぶ理由
- 今日の おねがい（「きょうは ヨコエビが たべたい」）
- ログインボーナス、季節イベント

### F. みんなと遊ぶ（サーバーが必要）
- 友だちの水槽を見に行く、着せ替えコンテスト

### 仲間の生き物の候補
ジュウモンジダコ（ダンボオクトパス）、センジュナマコ、オオグチボヤ、デメニギス、ダイオウグソクムシ、チョウチンアンコウ、コウモリダコ

## 決まったこと（2026-09）

- **2D で進める**（3D は必要になったら観賞モードとして検討）
- **大人も含めて遊ぶ**：文字は漢字かな交じり。かわいい口調は残す
- **基本は1日数分ときどきのぞく**。しっかり遊ぶ用に **深海探索（操作して潜る型）** を用意する
- **育てるのはめんだこだけ**。深海生物との出会いで **深海図鑑** が埋まる
- **水槽の模様替え** を入れる。置いた飾りに合わせて生き物が遊びに来て、図鑑に載る（ねこあつめ型）
- **デザインはスマホに最適化**（縦画面・片手の親指で操作。PC は同じ縦長の画面を中央に表示）
- ライブラリ：**Vite + TypeScript + PixiJS（描画）+ Svelte 5（画面まわり）+ Vitest**

## ロードマップ

- **Phase 1（済）** 新しい基盤（Vite + TS + PixiJS + Svelte）へ移行。v0.1 と同じ遊び
- **Phase 2（済）** 水槽の模様替え・生き物の来訪・深海図鑑
  - 飾り 13種・海底 4種。飾りのタグ（岩・砂・骨・熱水・光・サンゴ・かくれが）で、来る生き物が変わる
  - 30分ごとに来訪を抽選（最大3匹、2〜8時間滞在、閉じていた時間も最大12時間ぶん計算）
  - 図鑑はめんだこを含めて10種。解説の出典は `docs/zukan-sources.md`
  - 水槽を「海底・中層・上層」の3層で使う。めんだこは3層を行き来し、泳ぐ生き物は好む層に出る。
    浮かべる飾りは6種・上のほうまで置ける。画面が低い端末では縦方向だけ縮めて表示する
- **Phase 3（前半 済）** 深海探索（操作して潜る）。まず2ゾーンで手ざわりを確認
  - 下のボタン「もぐる」→ 行き先を選ぶ。げんきを20使う（寝ているとき・げんき不足は潜れない）
  - 画面のどこでも指でなぞって泳ぐ。カメラは自動で下へ進み、下のほうへ泳ぐと速く潜れる
  - 暗い海の中、めんだこのまわりの光の輪だけが見える。ちょうちんカチューシャを着けていると輪が大きい
  - 出会い方は3種類：ふつう（光の輪に1.5秒入れる）／恥ずかしがり（速く近づくと逃げる）／自分で光る（ライトを消すと会える）
  - 素材（貝がら・光る砂・クジラの骨片・きれいな石）とゴミを拾い、終わったら真珠に換える。底まで着くとボーナス
  - 失敗はゆるめ：探検ゲージが時間で減り、大きな影やゴミの塊にぶつかると大きく減って素材を1つ落とす。
    ゲージが尽きるか途中で浮上すると、素材の換金が半分。図鑑の記録は失わない
  - ゾーン：中深層（200〜1000m、最初から）・漸深層（1000〜3000m、図鑑6種で解放）
  - 探索でしか会えない生き物7種を追加し、図鑑は全17種
- **Phase 3（後半）** 深海層・超深海層（センジュナマコ、シンカイクサウオなど）、素材の使い道の追加を検討
- **音・PWA（済）**
  - 効果音：音声ファイルを使わず Web Audio で合成（なでる・ごはん・買う・出会う・ぶつかる など約30種）。音階は BGM と同じ D のペンタトニック
  - BGM：ゆらぐ環境音楽。オルゴール風の音を不規則に鳴らし、低い持続音・海の響き・泡を重ねる。
    水槽／おやすみ／ミニゲーム／探索（深いほど暗く静か）で雰囲気が変わる
  - 最初から効果音・BGM ともオン（鳴るのは最初のタップのあと）。設定でオン/オフと音量。別のアプリに移ると止まる
  - GitHub Pages 版は PWA：ホーム画面に置けて、オフラインでも遊べる。更新は次に開いたときに反映
- **その先** 手ざわりのバランス調整

## 技術構成

- `src/game/` … 描画に依存しない状態とルール。`npm test` でテスト
- `src/app/` … 画面の操作とルールをつなぐ（actions）、演出の通知（events）、保存しない画面の状態
- `src/art/` … 絵（SVG 文字列）。仮デザインなので、あとで差し替えやすいようここにまとめる
- `src/world/` … PixiJS の描画（水槽、深海の粒、ミニゲーム、深海探索）
- `src/audio/` … 音。`score.ts`（どの音をいつ鳴らすか・テストあり）、`sfx.ts`（効果音）、`ambient.ts`（BGM）、`engine.ts`（AudioContext）
- `src/ui/` … Svelte の画面部品（HUD、下から出るシート、お祝いなど）
- PixiJS の canvas（世界）の上に Svelte の DOM（UI）を重ねる構成
