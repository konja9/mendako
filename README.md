# しんかいぷかぷか（仮）

深海いきものを育てて、着せ替えて、眺めて癒やされるブラウザゲーム。
最初のキャラクターは **めんだこ**。

- ごはん・なでる・ねる でお世話すると、なかよし度がたまって大きくなる
- ミニゲーム「マリンスノーキャッチ」で しんじゅ を集める
- しんじゅで リボン・おうかん・ちょうちんカチューシャ・からだのいろ などを買って着せ替え（試着もできる）

## 動かしかた

Node.js 20 以上が必要です。インストールするパッケージはありません。

```sh
npm start        # http://localhost:5173/ で起動
npm test         # ゲームのルール（src/game）のテスト
```

ES Modules を使っているので、`index.html` をファイルとして直接開くのではなく、上のサーバー経由で開いてください。

## ファイル構成

```
index.html          画面の骨組み
src/main.js         画面の組み立てと操作
src/style.css       見た目
src/game/           描画に依存しない状態とルール（2D/3D どちらでも使える）
src/view/           2D 描画（めんだこ SVG・背景・ミニゲーム）
tests/              ルールのテスト
docs/game-design.md ゲームデザインメモ（2D/3D の比較、ゲーム性の候補、決めたいこと）
```
